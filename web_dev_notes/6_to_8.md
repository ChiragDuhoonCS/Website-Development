# Video 6 — SEO & Core Web Vitals in HTML

## 1. SEO

**SEO = Search Engine Optimization**

* Process of improving a website so it can rank better in search engines.
* Search engines consider many factors, including **content, performance, and user experience**.
* If two websites have similar content, a faster/better-performing website can have an advantage. ([Video Highlight][2])

### Example

A website like Amazon needs pages to load quickly because users expect a fast experience.

---

## 2. Core Web Vitals

Core Web Vitals are performance/user-experience metrics used to evaluate webpages.

The video explains three important metrics:

### CLS — Cumulative Layout Shift

Measures how much the page layout **unexpectedly moves while loading**.

Example:

```text
Page loading
     ↓
Button appears
     ↓
Image loads
     ↓
Button moves
```

This can cause users to click the wrong thing.

**Goal:** Keep CLS as low as possible. ([Video Highlight][2])

---

### LCP — Largest Contentful Paint

Measures how quickly the **largest visible content element** loads.

Target discussed:

```text
LCP ≤ 2.5 seconds
```

A lower LCP means the main content becomes visible faster. ([Video Highlight][2])

---

### FID — First Input Delay

Measures the delay between a user's first interaction and the browser responding to it.

Target discussed:

```text
FID < 100 ms
```

Lower delay = more responsive website. ([Video Highlight][2])

---

## 3. Lighthouse

**Lighthouse** is a Chrome tool used to analyze a webpage.

It provides reports for areas such as:

* Performance
* Accessibility
* Best Practices
* SEO

It can be run for:

* **Mobile**
* **Desktop**

The report also gives suggestions for improvement, such as optimizing images and specifying appropriate image dimensions. ([Video Highlight][2])

### Basic process

```text
Open webpage
     ↓
Chrome DevTools
     ↓
Lighthouse
     ↓
Generate report
     ↓
Check problems + suggestions
```

---

## 4. Meta Description

A meta description describes the webpage.

```html
<meta name="description"
      content="This is my website">
```

It gives search engines information about the page and can be useful for search-result presentation. ([Video Highlight][2])

---

## 5. Meta Keywords

Older websites used:

```html
<meta name="keywords"
      content="HTML, CSS, JavaScript">
```

But **meta keywords are largely deprecated/not useful for modern search ranking** because they were abused by webmasters. ([Video Highlight][3])

---

## 6. Mobile Preview

The video demonstrates checking how a website appears on a **mobile screen** using browser developer tools.

Important because websites should work properly on different screen sizes.

---

## 7. Other Performance Terms

The Lighthouse report also introduces terms such as:

* **FCP — First Contentful Paint** → when the first piece of page content appears.
* **LCP — Largest Contentful Paint**
* **TBT — Total Blocking Time**

For deeper explanations of web-performance metrics, the video points toward **web.dev**. ([Video Highlight][2])

```text
Meta keywords → Mostly obsolete
```

# Video 7 — Forms & Input Tags in HTML

## 1. HTML Forms

A **form** collects data from users and submits it for processing.

Examples:

* Contact forms
* Exam registration
* Ticket/reservation forms

Basic structure:

```html
<form>
    ...
</form>
```

A form can send collected data to a server. ([Video Highlight][4])

---

## 2. `action`

The `action` attribute specifies **where the submitted form data should be sent**.

```html
<form action="submit.php">
```

---

## 3. GET vs POST

Forms can use:

```html
<form method="get">
```

or

```html
<form method="post">
```

### GET

* Used for simpler requests.
* Data is generally included in the URL.
* Has limitations on the amount of data.
* Not appropriate for sensitive information such as passwords.

### POST

* Sends data in the request body.
* Suitable for larger amounts of submitted data.
* Preferred for sensitive form data such as passwords.

([Video Highlight][4])

---

## 4. `<input>`

`<input>` creates an input field.

```html
<input type="text">
```

### Common attributes

```html
<input
    type="text"
    name="username"
    placeholder="Enter your username">
```

* `type` → type of input.
* `name` → identifies the submitted data.
* `placeholder` → hint shown inside the field.

The placeholder disappears when the user starts typing. ([Video Highlight][4])

---

## 5. Input Types

The video demonstrates different types, including:

```html
<input type="text">
<input type="date">
<input type="radio">
<input type="checkbox">
```

The `type` attribute determines the kind of input control displayed.

---

## 6. `<label>`

A label tells the user what an input field is for.

```html
<label for="username">Enter your username:</label>

<input type="text" id="username">
```

### Important connection

```text
label for="username"
        ↓
input id="username"
```

The `for` value should match the input's `id`.

This association is also important for accessibility. ([Video Highlight][4])

---

## 7. Radio Buttons

Used when the user should select **one option from a group**.

```html
<input type="radio" name="gender" value="male">
<label>Male</label>

<input type="radio" name="gender" value="female">
<label>Female</label>
```

### Important

Radio buttons must have the **same `name`** to form one selection group.

```text
name="gender"
      ↓
Male   OR   Female
```

Only one can be selected from that group. ([Video Highlight][4])

---

## 8. Checkbox

Checkboxes allow **multiple independent selections**.

```html
<input type="checkbox" name="newsletter">
<label>Subscribe to newsletter</label>
```

### Difference

```text
Radio     → one choice from a group
Checkbox  → multiple choices possible
```

---

## 9. `<div>`

`<div>` is a **block-level element**.

It can be used to group/form elements and help structure the form.

---

## 10. `<br>`

```html
<br>
```

Creates a line break.

The video discourages using lots of `<br>` tags simply for layout/spacing; proper CSS should handle layout and spacing. ([Video Highlight][4])

---

## 11. `<textarea>`

Used for **multi-line text input**.

```html
<textarea
    rows="4"
    cols="30"
    placeholder="Enter your message">
</textarea>
```

* `rows` → visible height.
* `cols` → visible width.
* `placeholder` → input hint.

Useful for:

* Messages
* Comments
* Feedback
* Descriptions

([Video Highlight][4])

---

## 12. `<select>` and `<option>`

Creates a dropdown.

```html
<select name="fruit">
    <option value="apple">Apple</option>
    <option value="banana">Banana</option>
    <option value="cherry">Cherry</option>
</select>
```

* `<select>` → dropdown.
* `<option>` → individual choice.
* `value` → value sent when that option is selected.

---

## 13. `required`

Makes an input mandatory.

```html
<input type="text" required>
```

The form cannot be submitted normally until the required field is filled. ([Video Highlight][4])

---

## 14. `autofocus`

Automatically focuses an input when the page loads.

```html
<input type="text" autofocus>
```

The cursor starts in that field. ([Video Highlight][4])

---

## 15. Validation

HTML input fields can have validation rules.

The video mentions using patterns/regular expressions to restrict what users can enter.

Example:

```html
<input type="text" pattern="...">
```

The pattern can enforce a required format before submission. ([Video Highlight][4])

### Quick Revision

```text
<form>       → form
action       → where data is sent
method       → GET / POST
<input>      → input field
type         → input type
name         → submitted field name
placeholder  → input hint
<label>      → describes input
for + id     → connects label & input
radio        → one choice
checkbox     → multiple choices
<textarea>   → multi-line input
<select>     → dropdown
<option>     → dropdown option
required     → mandatory field
autofocus    → automatically focuses field
```

# Video 8 — Inline & Block Elements

## 1. Block Elements

A **block-level element** generally takes the **full available width**.

Example:

```html
<p>Hello</p>
<p>World</p>
```

The second paragraph starts on a new line.

Common examples:

```html
<div>
<p>
<h1>
<h2>
```

---

## 2. Inline Elements

An **inline element** takes only the **width required by its content**.

Example:

```html
<a href="#">Google</a>
<a href="#">YouTube</a>
```

They can appear on the same line.

Common examples:

```html
<a>
<span>
```

---

## 3. Main Difference

```text
BLOCK
┌──────────────────────────────┐
│ <p>                          │
└──────────────────────────────┘
┌──────────────────────────────┐
│ next element                 │
└──────────────────────────────┘

INLINE
[ <span> ] [ <a> ] [ <span> ]
```

### Remember

```text
Block  → full available width → new line
Inline → required width       → same line possible
```

([Video Highlight][5])

---

## 4. `<div>` vs `<span>`

### `<div>`

```html
<div>Hello</div>
```

* Block-level element.
* Takes available width.
* Subsequent content generally moves to the next line.

### `<span>`

```html
<span>Hello</span>
```

* Inline element.
* Takes only required width.
* Other inline content can remain beside it.

([Video Highlight][6])

---

## 5. Demonstration with CSS

The video uses background colors to make the difference visible.

```html
<p style="background-color: lightblue;">
    This is a paragraph.
</p>

<a href="#" style="background-color: red;">
    Google
</a>
```

The paragraph's background extends across the available width, while the anchor's background covers only its content area.

---

## 6. Display Property

CSS controls whether an element behaves as inline or block.

```css
display: block;
```

or

```css
display: inline;
```

So an element's default behavior can be changed using CSS. ([Video Highlight][6])

---

## 7. Spaces in HTML

HTML normally ignores **multiple consecutive spaces**.

For example:

```html
Hello       World
```

doesn't preserve all those spaces as separate visible spaces.

For an additional non-breaking space, use:

```html
&nbsp;
```

Example:

```html
Hello&nbsp;&nbsp;World
```

([Video Highlight][5])

---

## 8. Block vs Inline — Important Points

| Block                           | Inline                            |
| ------------------------------- | --------------------------------- |
| Takes available/full width      | Takes required width              |
| Starts on a new line            | Can stay on same line             |
| `<div>`, `<p>`                  | `<span>`, `<a>`                   |
| Can push following content down | Doesn't normally force a new line |

The video also provides a broader list of HTML elements and encourages identifying whether elements are inline or block through practice. ([Video Highlight][5])

---

```text
display: block;

```
