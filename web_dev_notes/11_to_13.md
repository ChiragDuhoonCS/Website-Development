# Video 11 — Semantic Tags in HTML

## 1. Semantic HTML

**Semantic tags** clearly describe the meaning/purpose of their content.

Example:

```html
<header>...</header>
<nav>...</nav>
<main>...</main>
<footer>...</footer>
```

The tag itself tells us what the content represents.

### Why use semantic tags?

* Makes HTML easier to understand.
* Improves **accessibility**.
* Helps **search engines** understand page structure.
* Makes code easier to maintain.

---

## 2. `<header>`

Represents the **header/introduction** of a page or section.

```html
<header>
    <h1>My Website</h1>
</header>
```

It can contain:

* Logo
* Heading
* Navigation
* Introductory content

---

## 3. `<nav>`

Represents a section containing **navigation links**.

```html
<nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
    <a href="/contact">Contact</a>
</nav>
```

Used for important navigation links.

---

## 4. `<main>`

Contains the **main content** of the webpage.

```html
<main>
    <h1>Welcome</h1>
    <p>Main page content...</p>
</main>
```

A page generally has one main `<main>` element.

---

## 5. `<section>`

Represents a **thematic section** of content.

```html
<section>
    <h2>About Me</h2>
    <p>Information about me...</p>
</section>
```

A section normally has a heading describing its content.

---

## 6. `<article>`

Represents **independent/self-contained content**.

Examples:

* Blog post
* News article
* Forum post
* Product/article entry

```html
<article>
    <h2>My First Blog</h2>
    <p>Blog content...</p>
</article>
```

The content should make sense even when considered separately.

---

## 7. `<aside>`

Contains content that is **related to the main content but not part of it**.

Examples:

* Sidebar
* Related links
* Additional information
* Advertisements

```html
<aside>
    <h3>Related Articles</h3>
</aside>
```

---

## 8. `<footer>`

Represents the footer of a page or section.

```html
<footer>
    Copyright © 2026
</footer>
```

Can contain:

* Copyright information
* Contact information
* Additional links
* Related information

---

## 9. Semantic Page Structure

A typical page:

```text
┌─────────────────────┐
│       HEADER        │
├─────────────────────┤
│        NAV          │
├─────────────────────┤
│                     │
│        MAIN         │
│   ┌──────────────┐  │
│   │   SECTION    │  │
│   │   ARTICLE    │  │
│   └──────────────┘  │
│                     │
│       ASIDE         │
├─────────────────────┤
│       FOOTER        │
└─────────────────────┘
```

### Quick Revision

```text
<header>  → header/introduction
<nav>     → navigation
<main>    → main content
<section> → thematic section
<article> → independent content
<aside>   → related/side content
<footer>  → footer
```

**Semantic HTML = HTML that describes the meaning of the content.**

# Video 12 — Entities, Code Tags & More HTML

## 1. HTML Entities

Some characters have special meanings in HTML.

For example:

```html
<
>
&
```

If you want to display certain special characters as text, HTML provides **entities**.

### Common entities

| Entity   | Displays           |
| -------- | ------------------ |
| `&lt;`   | `<`                |
| `&gt;`   | `>`                |
| `&amp;`  | `&`                |
| `&nbsp;` | Non-breaking space |
| `&copy;` | ©                  |

Example:

```html
<p>5 &lt; 10</p>
```

Displays:

```text
5 < 10
```

---

## 2. Non-Breaking Space

```html
&nbsp;
```

Creates a space that the browser does not normally collapse/break like ordinary spaces.

Example:

```html
<p>Hello&nbsp;&nbsp;World</p>
```

---

## 3. HTML Comments

Comments are ignored by the browser.

```html
<!-- This is a comment -->
```

Useful for:

* Explaining code.
* Leaving notes.
* Temporarily disabling HTML.

---

## 4. Code-Related HTML Tags

HTML provides tags for displaying computer code and related information.

### `<code>`

Represents a piece of computer code.

```html
<code>printf("Hello");</code>
```

---

### `<pre>`

Preserves formatting such as spaces and line breaks.

```html
<pre>
Hello
    World
        HTML
</pre>
```

Useful when formatting/spacing must be preserved.

---

### `<kbd>`

Represents **keyboard input**.

```html
<kbd>Ctrl</kbd> + <kbd>C</kbd>
```

---

### `<samp>`

Represents **sample output** from a computer program.

```html
<samp>Hello World</samp>
```

---

### `<var>`

Represents a **variable**.

```html
<var>x</var>
```

---

## 5. Quotations

### `<blockquote>`

Used for a longer quotation.

```html
<blockquote>
    This is a quoted text.
</blockquote>
```

### `<q>`

Used for a short inline quotation.

```html
<p>He said <q>Hello</q>.</p>
```

### Difference

```text
<blockquote> → longer quotation
<q>          → short inline quotation
```

---

## 6. Abbreviation

`<abbr>` represents an abbreviation.

```html
<abbr title="HyperText Markup Language">
    HTML
</abbr>
```

The `title` provides the full meaning.

---

## 7. Address

`<address>` represents contact information for the relevant person/organization.

```html
<address>
    Contact: example@email.com
</address>
```

---

## 8. `<time>`

Represents a date/time.

```html
<time datetime="2026-08-24">
    August 24, 2026
</time>
```

The `datetime` attribute provides a machine-readable date/time value.

---

### Quick Revision

```text
&lt;     → <
&gt;     → >
&amp;    → &
&nbsp;   → non-breaking space
&copy;   → ©

<!-- --> → comment

<code>   → code
<pre>    → preserves formatting
<kbd>    → keyboard input
<samp>   → program output
<var>    → variable

<blockquote> → long quotation
<q>          → short quotation
<abbr>       → abbreviation
<address>    → contact information
<time>       → date/time
```

# Video 13 — Introduction to CSS

## 1. What is CSS?

**CSS = Cascading Style Sheets**

CSS is used to control the **appearance and presentation** of HTML elements.

HTML:

```text
Structure
```

CSS:

```text
Style / Design
```

JavaScript:

```text
Functionality
```

---

## 2. Why CSS?

Without CSS, HTML pages are mostly plain/default browser styling.

CSS allows you to control things such as:

* Colors
* Fonts
* Sizes
* Spacing
* Backgrounds
* Borders
* Layout
* Positioning

---

## 3. CSS Syntax

Basic syntax:

```css
selector {
    property: value;
}
```

Example:

```css
p {
    color: red;
}
```

### Parts

```text
p
↓
Selector

color
↓
Property

red
↓
Value
```

So:

```css
p {
    color: red;
}
```

means: make the text of `<p>` red.

---

## 4. Three Ways to Add CSS

### 1. Inline CSS

CSS is written directly inside the HTML element.

```html
<p style="color: red;">
    Hello
</p>
```

Uses the `style` attribute.

---

### 2. Internal CSS

CSS is written inside `<style>` in the HTML `<head>`.

```html
<head>
    <style>
        p {
            color: red;
        }
    </style>
</head>
```

Useful when styling a single HTML document.

---

### 3. External CSS

CSS is stored in a separate `.css` file.

`style.css`:

```css
p {
    color: red;
}
```

HTML:

```html
<link rel="stylesheet" href="style.css">
```

External CSS is generally preferred for larger websites because the same stylesheet can be reused across multiple pages.

---

## 5. CSS Selectors

A selector determines **which HTML elements will be styled**.

### Element selector

```css
p {
    color: red;
}
```

Targets all `<p>` elements.

---

### ID selector

HTML:

```html
<p id="para1">Hello</p>
```

CSS:

```css
#para1 {
    color: red;
}
```

Uses:

```text
#id
```

---

### Class selector

HTML:

```html
<p class="red">Hello</p>
```

CSS:

```css
.red {
    color: red;
}
```

Uses:

```text
.class
```

---

## 6. Grouping Selectors

Multiple selectors can share the same styling.

```css
h1, h2, p {
    color: blue;
}
```

This applies the same rule to:

```text
h1
h2
p
```

---

## 7. CSS Comments

CSS comments:

```css
/* This is a CSS comment */
```

They are ignored by the browser.

---

## 8. Important CSS Concept — Cascading

CSS is called **Cascading Style Sheets** because multiple style rules can apply to the same element.

When conflicts occur, the browser determines which rule takes precedence based on factors such as:

* Importance
* Specificity
* Source/order

Basic selector specificity idea:

```text
Element < Class < ID
```

For example:

```css
p {
    color: blue;
}

.red {
    color: red;
}

#special {
    color: green;
}
```

An element matching all three selectors will generally get the ID rule because it has greater specificity.

---

## 9. Basic CSS Example

HTML:

```html
<h1 id="title">My Website</h1>

<p class="text">
    Welcome to my website.
</p>
```

CSS:

```css
#title {
    color: blue;
}

.text {
    color: red;
}
```

Result:

```text
My Website        → blue
Welcome...        → red
```
