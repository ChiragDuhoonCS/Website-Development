# Video 9 — ID & Classes in HTML

## 1. What is an ID?

`id` is an HTML attribute used to **uniquely identify an element**.

```html
<div id="firstdiv">
    Hello
</div>
```

* `id` → attribute
* `"firstdiv"` → ID value
* An ID should be **unique** within a page.

Think of ID as a unique identification number for an element.

---

## 2. Why use IDs?

IDs are useful when you want to:

* Identify one particular element.
* Target a specific element with CSS.
* Later target an element using JavaScript.
* Create links that jump to a particular location on a page.

Example:

```html
<h1 id="heading">My Website</h1>
```

---

## 3. ID in CSS

An ID selector uses `#`.

HTML:

```html
<div id="redbox">
    Hello
</div>
```

CSS:

```css
#redbox {
    color: red;
}
```

```text
# + id-name
      ↓
CSS ID selector
```

---

## 4. What is a Class?

`class` is an HTML attribute used to **group elements**.

```html
<div class="box">One</div>
<div class="box">Two</div>
<div class="box">Three</div>
```

All three elements have the same class.

Unlike an ID, a class **can be used on multiple elements**. ([Video Highlight][2])

---

## 5. Why use Classes?

Classes are mainly useful when the **same styling needs to be applied to multiple elements**.

Example:

```html
<p class="red">Hello</p>
<p class="red">World</p>
<p class="red">HTML</p>
```

CSS:

```css
.red {
    color: red;
}
```

All three paragraphs become red.

---

## 6. Class Selector in CSS

A class selector uses `.`:

```css
.red {
    color: red;
}
```

```text
. + class-name
       ↓
CSS class selector
```

### ID vs Class

| ID                                   | Class                          |
| ------------------------------------ | ------------------------------ |
| Should uniquely identify one element | Can be shared by many elements |
| CSS selector → `#`                   | CSS selector → `.`             |
| `id="box"`                           | `class="box"`                  |

---

## 7. ID and Class Together

An element can have **both an ID and a class**:

```html
<div id="first" class="red">
    Hello
</div>
```

CSS:

```css
#first {
    background-color: yellow;
}

.red {
    color: red;
}
```

Both styles can apply to the same element.

---

## 8. Multiple Classes

An element can also have **multiple classes**.

```html
<div class="red bold">
    Hello
</div>
```

CSS:

```css
.red {
    color: red;
}

.bold {
    font-weight: bold;
}
```

The element gets the styling from both classes.

---

```text
Class selector  → .class

class="box"

```

# Video 10 — Video, Audio & Media in HTML

## 1. `<video>` Tag

HTML provides the `<video>` element to embed video directly into a webpage.

Basic syntax:

```html
<video src="video.mp4"></video>
```

* `<video>` → embeds video.
* `src` → specifies video file/location.

The video demonstrates using an MP4 file. ([YouTube][3])

---

## 2. Video Width & Height

```html
<video src="video.mp4"
       width="555"
       height="300">
</video>
```

* `width` → video width.
* `height` → video height.
* In these HTML attributes, you don't write `px`.

---

## 3. `controls`

Without controls, the user may not have the normal video controls.

```html
<video src="video.mp4" controls></video>
```

`controls` provides controls such as:

* Play/pause
* Volume
* Fullscreen
* Download, depending on browser

([Video Highlight][4])

---

## 4. Responsive Video

A fixed width can cause problems on smaller screens.

CSS can be used to make the video responsive:

```css
video {
    width: 100%;
    max-width: 100%;
}
```

The idea is that the video should adapt to the available screen width.

---

## 5. `autoplay`

Automatically starts the video when the page loads:

```html
<video src="video.mp4" autoplay></video>
```

However, browsers often restrict autoplay when the video has sound.

---

## 6. `loop`

Automatically repeats the video after it finishes.

```html
<video src="video.mp4" loop></video>
```

Process:

```text
Play → End → Start again → End → Start again...
```

---

## 7. `muted`

Starts the video without sound:

```html
<video src="video.mp4" muted></video>
```

`muted` is particularly relevant when using autoplay because browsers commonly allow muted autoplay more readily.

---

## 8. `autoplay + muted`

A common combination:

```html
<video
    src="video.mp4"
    autoplay
    muted>
</video>
```

This allows a video to start automatically without sound.

---

## 9. `poster`

`poster` specifies an image displayed **before the video starts**.

```html
<video
    src="video.mp4"
    poster="thumbnail.jpg"
    controls>
</video>
```

```text
Before play → thumbnail.jpg
       ↓
User presses play
       ↓
Video starts
```

([Video Highlight][4])

---

# 10. `<audio>` Tag

HTML also provides `<audio>` for embedding audio.

Basic syntax:

```html
<audio src="audio.mp3"></audio>
```

Usually you want controls:

```html
<audio src="audio.mp3" controls></audio>
```

The browser then provides audio controls for the user. ([Video Highlight][5])

---

## 11. Audio `loop`

```html
<audio src="audio.mp3" controls loop></audio>
```

After the audio ends, it starts again automatically.

```text
Play → End → Play → End → ...
```

---

## 12. Audio `muted`

```html
<audio src="audio.mp3" controls muted></audio>
```

Starts with the audio muted.

---

## 13. `preload`

`preload` tells the browser how much media data should be loaded before the user plays it.

Possible values:

### `none`

```html
<audio src="audio.mp3" preload="none"></audio>
```

Don't preload the audio.

### `metadata`

```html
<audio src="audio.mp3" preload="metadata"></audio>
```

Load metadata such as duration, but not the complete audio.

### `auto`

```html
<audio src="audio.mp3" preload="auto"></audio>
```

Allows the browser to preload more of the media.

```text
preload
 ├── none
 ├── metadata
 └── auto
```

([Video Highlight][5])

---

# 14. SVG

**SVG = Scalable Vector Graphics**

SVG is used for creating graphics directly in HTML.

Basic example:

```html
<svg>
    ...
</svg>
```

SVG graphics are vector-based, so they can scale without becoming pixelated.

Common SVG elements include:

```text
<circle>    → circle
<rect>      → rectangle
<line>      → line
<ellipse>   → ellipse
<polygon>   → polygon
<path>      → custom path/shape
<text>      → text
```

Useful for things such as:

* Icons
* Logos
* Graphics
* Illustrations

---

# 15. `<iframe>`

`<iframe>` allows another webpage/resource to be **embedded inside your webpage**.

Basic syntax:

```html
<iframe src="https://example.com"></iframe>
```

A common example is embedding a YouTube video.

YouTube's **Share → Embed** option can provide an iframe code that you can place into your HTML.

Concept:

```text
Your webpage
┌─────────────────────────┐
│                         │
│   Embedded content      │
│       <iframe>          │
│                         │
└─────────────────────────┘
```

The video also explains that an iframe can preserve a specified YouTube video's starting point when the embed URL contains the appropriate timestamp. ([LinkedIn][6])
